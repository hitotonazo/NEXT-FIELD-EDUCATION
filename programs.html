LABS

出前授業から継続プログラム、案内先までの流れが分かるように、構造図とあわせてご紹介します。

選抜型継続プログラムの流れ

学校現場での出前授業から、記録・選抜・案内までを一連の流れで設計しています。

01

出前授業

中学・高校で短時間の授業を実施し、反応・発言・集団内の振る舞いを観察します。

›
02

記録化

行動ログ・会話ログを整理し、継続対象候補の特徴を見える化します。

›
03

少人数選抜

継続面談と追加課題を通して、適性の高い参加者を絞り込みます。

›
04

継続案内

記録・分析・配置を軸にした能力開発を行い、次の現場へ案内します。

A

Field Scout Session

観察の入口となる出前授業。反応速度や場の変化への関わり方を確認します。

B

Signal Mapping Lab

個別記録と小人数演習により、選抜後の特徴を構造化していく段階です。

C

Fixed Route Support

継続後の案内先へ向けて、役割・運用・配置を固定していく段階です。

dispatch program

Field Scout Session

荒れ気味の学校現場へ訪問し、短時間の演習から反応特性を読み取る導入授業です。

  • 対象中学・高校
  • 重点主導性 / 反応速度 / 影響力
selection program

Signal Mapping Lab

出前授業後に選抜された参加者向けの記録・対話プログラム。行動傾向を可視化します。

  • 形式少人数選抜
  • 記録AI判定用ログ生成
placement route

Fixed Route Support

修了後は次の現場へ案内します。本人の特性に合った継続先を個別に案内します。

  • 案内先実践拠点 / 監理施設
  • 進路運営側が最終決定
